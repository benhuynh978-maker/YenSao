Đây là trang demo độc lập để thử nghiệm kiến trúc "AI chat nhúng có tool" (relay server giấu API key + vòng lặp function-calling + tách tool client/server), theo tài liệu AI-Chat-Nhung-Co-Tool.md.

Lưu ý: Nhóm A — chat này gọi Supabase THẬT của site chính (chỉ đọc dữ liệu công khai: sản phẩm/flash sale/thông tin cửa hàng), không cần đăng nhập. Không có tool tra đơn hàng/ưu đãi cá nhân (Nhóm B tạm hoãn). Bấm bong bóng chat ở góc phải dưới để thử.
